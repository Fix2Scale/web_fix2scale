# Fix 2 Scale · sitio web

Next.js 16 App Router, TypeScript, CSS global con tokens (sin Tailwind). Bilingüe: ES sin
prefijo, EN bajo `/en`. Ver `README.md` para el modelo de contenido y las rutas.

Reglas de marca (del design system): sin degradados, sin blur, sin sombras salvo menús
flotantes, sin emoji, radio 0 (chips 2–4px), lima `#c0f541` en exactamente un elemento por
página y nunca sobre blanco. Display en Roboto `wdth 75 / wght 900` en caja alta; cuerpo en
Plus Jakarta Sans. Cifras con `tnum`. Todo color y tamaño sale de las variables de `globals.css`.

El cliente de los casos es siempre anónimo ("una universidad privada colombiana"); las cifras
publicables viven solo en `content/casos.json` y las proyecciones se rotulan como proyección.
